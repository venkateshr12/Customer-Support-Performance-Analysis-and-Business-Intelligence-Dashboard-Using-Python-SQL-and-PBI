# Customer Support Performance Analysis and Business Intelligence Dashboard

An end-to-end data analytics project using Python, SQL, and Microsoft Power BI to analyze customer support tickets and generate actionable business insights.

## 📌 Project Overview

Customer support teams handle tickets across different issue types, priorities, and communication channels. Analyzing this data helps identify workload patterns, monitor response performance, understand customer satisfaction, and investigate escalations.

This project explores and cleans a customer support dataset using Python, performs basic SQL analysis, and presents the findings through an interactive Power BI dashboard.

## 🎯 Project Objectives

- Explore the structure and quality of the dataset.
- Handle missing values, duplicate records, and data types.
- Perform exploratory data analysis (EDA).
- Create visualizations to identify patterns and trends.
- Execute basic SQL queries for data analysis.
- Build an interactive Power BI dashboard with KPIs and slicers.
- Generate meaningful business insights and recommendations.

## 🛠️ Technologies Used

- **Python** – Data exploration and cleaning
- **Pandas and NumPy** – Data manipulation and numerical analysis
- **Matplotlib and Seaborn** – Data visualization
- **SQL** – Data querying, filtering, grouping, and aggregation
- **Microsoft Power BI** – Interactive dashboard and KPI reporting
- **CSV** – Dataset storage and exchange

## 📂 Dataset

**File:** `customer_support_dataset.csv`

The dataset includes fields related to:

- Ticket ID and customer ID
- Issue type and priority
- Support channel and ticket status
- Created date and resolved date
- Response time and resolution time
- Customer satisfaction score
- Escalation flag and region
- Agent information

## 🔄 Project Workflow

1. **Data Exploration:** Inspect rows, columns, data types, missing values, and duplicates.
2. **Data Cleaning:** Handle missing values, remove duplicate records where necessary, and correct data types.
3. **Exploratory Data Analysis:** Analyze ticket counts, response times, resolution times, satisfaction, and escalations.
4. **SQL Analysis:** Use basic SQL operations such as `SELECT`, `WHERE`, `GROUP BY`, `ORDER BY`, `COUNT`, and `AVG`.
5. **Dashboard Development:** Build KPI cards, charts, and interactive slicers in Power BI.
6. **Business Insights:** Interpret results and identify opportunities to improve customer support operations.

## 📊 Power BI Dashboard Features

- Total ticket and open ticket KPIs
- Monthly ticket volume trend
- Ticket distribution by status
- Ticket volume by issue type
- Average response time by support channel
- Customer satisfaction analysis
- Escalation rate by priority
- Interactive filters for date, priority, and channel

## 💡 Business Insights

The project investigates questions such as:

- Which issue types generate the most tickets?
- How does ticket workload vary by status and priority?
- Which support channels have higher average response times?
- How does customer satisfaction differ across issue categories?
- Which priorities or issue types have higher escalation rates?

Findings should be interpreted using the actual dashboard results and the selected filters.
